# نظام تسيير الثانويات الجزائري

تطبيق ويب شامل مصمم لتسيير التقييمات المدرسية والبيانات الأكاديمية في السياق التعليمي الجزائري. يدعم هذا النظام أدواراً متعددة، وواجهات متعددة اللغات، وسير عمل إداري مبسط.

## 🚀 الميزات الرئيسية

- **دعم أدوار متعددة**: لوحات تحكم مخصصة لـ **المديرين**، **الأساتذة**، و**مديري الدراسات**.
- **واجهة مستخدم متعددة اللغات**: دعم كامل للعربية (RTL)، الفرنسية، الإنجليزية، الألمانية، التركية، والأمازيغية.
- **التسيير الأكاديمي**:
  - تسجيل وتتبع الطلاب والأقسام.
  - تسيير المواد بمعاملات محددة.
  - التقييم الفصلي (الثلاثي) وإدخال النقاط.
- **إعداد تلقائي**: نص برمجبي PowerShell مخصص لإعداد البيئة المحلية بسرعة على نظام Windows.
- **التقارير**: توليد رؤى إحصائية وتقارير أكاديمية.

## 🛠️ التكنولوجيا المستخدمة

### الواجهة الأمامية
- **الإطار**: [Next.js 14](https://nextjs.org/) (App Router)
- **مكتبة الواجهة**: [Material UI (MUI)](https://mui.com/)
- **التحريك**: [Framer Motion](https://www.framer.com/motion/)
- **التدويل**: [next-intl](https://next-intl-docs.vercel.app/)

### الواجهة الخلفية
- **بيئة التشغيل**: [Node.js](https://nodejs.org/) مع **Express.js**
- **اللغة**: [TypeScript](https://www.typescriptlang.org/)
- **ORM**: [Prisma](https://www.prisma.io/)
- **التحقق**: [Zod](https://zod.dev/)

### قاعدة البيانات
- **المحرك**: [PostgreSQL](https://www.postgresql.org/)

## 🏃 ابدأ هنا

### المتطلبات الأساسية

- **Node.js**: الإصدار 18.x أو أعلى.
- **PostgreSQL**: الإصدار 14 أو أعلى.

### التثبيت التلقائي (موصى به لـ Windows)

1. افتح طرفية PowerShell في المجلد الرئيسي.
2. قم بتشغيل نص الإعداد:
   ```powershell
   ./setup.ps1
   ```
3. اتبع التعليمات التي تظهر على الشاشة.
