# Système de Gestion Scolaire Algérienne

Une application web complète conçue pour gérer les évaluations scolaires et les données académiques dans le contexte éducatif algérien. Ce système prend en charge plusieurs rôles, des interfaces multilingues et des flux de travail administratifs simplifiés.

## 🚀 Fonctionnalités Clés

- **Support Multi-Rôles** : Tableaux de bord personnalisés pour les **Administrateurs**, **Enseignants** et **Directeurs**.
- **UI Multilingue** : Support complet pour l'Arabe (RTL), le Français, l'Anglais, l'Allemand, le Turc et le Tamazight.
- **Gestion Académique** :
  - Enregistrement et suivi des élèves et des classes.
  - Gestion des matières avec des coefficients spécifiques.
  - Évaluation trimestrielle et saisie des notes.
- **Configuration Automatisée** : Un script PowerShell dédié pour une configuration rapide de l'environnement local sur Windows.
- **Rapports** : Génération d'aperçus statistiques et de rapports académiques.

## 🛠️ Stack Technique

### Frontend
- **Framework** : [Next.js 14](https://nextjs.org/) (App Router)
- **Librairie UI** : [Material UI (MUI)](https://mui.com/)
- **Animations** : [Framer Motion](https://www.framer.com/motion/)
- **Internationalisation** : [next-intl](https://next-intl-docs.vercel.app/)

### Backend
- **Runtime** : [Node.js](https://nodejs.org/) avec **Express.js**
- **Langage** : [TypeScript](https://www.typescriptlang.org/)
- **ORM** : [Prisma](https://www.prisma.io/)
- **Validation** : [Zod](https://zod.dev/)

### Base de Données
- **Moteur** : [PostgreSQL](https://www.postgresql.org/)

## 🏃 Pour Commencer

### Prérequis

- **Node.js** : Version 18.x ou supérieure.
- **PostgreSQL** : Version 14 ou supérieure.

### Installation Automatisée (Recommandée pour Windows)

1. Ouvrez un terminal PowerShell dans le répertoire racine.
2. Exécutez le script de configuration :
   ```powershell
   ./setup.ps1
   ```
3. Suivez les instructions à l'écran.
