# Anagraw n Usefrek n Yiɣerbazen n Lezzayer

D asnas n uweb ummid yettwasunfen i usefrek n yikayaden n uɣerbaz d yisalan n tmaskant deg ljiha n uselmed n Lezzayer. Anagraw-a iqubel aṭas n tmerwin, tinfal n waṭas n tutlayin d yisiraten n usefrek isehlan.

## 🚀 Tigawin Tigjdanin

- **Iqubel aṭas n tmerwin**: Ifuyla n uselkim i **Inedbalen**, **Iselmaden** d **Ineyyafen**.
- **Tanfult n waṭas n tutlayin**: Iqubel s lekmal Taɛrabt (RTL), Tafransist, Tegnizit, Talmanit, Taturkit d Tamaziɣt.
- **Asefrek n Tmaskant**:
  - Ajerred d uḍfar n yinelmaden d tneɣriyin.
  - Asefrek n timsirin s imasalen iherzen.
  - Akayad akraḍyuran d usekcem n tneqqiḍin.
- **Asegreres imezgi**: Agreres n PowerShell i usegreres n tiddit n lqaɛa deg Windows.
- **Ineqqisen**: Asnulfu n tidaddanin d yineqqisen n tmaskant.

## 🛠️ Ttawilat n Teknulujit

### Tanfult n zdat
- **Iseɣzan**: [Next.js 14](https://nextjs.org/) (App Router)
- **Tamkarḍit n UI**: [Material UI (MUI)](https://mui.com/)
- **Imussuten**: [Framer Motion](https://www.framer.com/motion/)
- **Agraɣlan**: [next-intl](https://next-intl-docs.vercel.app/)

### Tanfult n deffir
- **Tidder**: [Node.js](https://nodejs.org/) s **Express.js**
- **Tutlayt**: [TypeScript](https://www.typescriptlang.org/)
- **ORM**: [Prisma](https://www.prisma.io/)
- **Aseɣbel**: [Zod](https://zod.dev/)

### Taffist n isalan
- **Amseddar**: [PostgreSQL](https://www.postgresql.org/)

## 🏃 Beddu n uxeddim

### Ayen iwatan

- **Node.js**: Tasiwelt 18.x neɣ s ufella.
- **PostgreSQL**: Tasiwelt 14 neɣ s ufella.

### Asegreres imezgi (Yettwaweṣṣa i Windows)

1. Ldi asir n PowerShell deg ukaram n lqaɛa.
2. Sselmed agreris n usgereres:
   ```powershell
   ./setup.ps1
   ```
3. Ḍfer tinfal n uselkim.
