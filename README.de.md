# Algerisches Schulverwaltungssystem

Eine umfassende Webanwendung zur Verwaltung von Schulbewertungen und akademischen Daten im algerischen Bildungskontext. Dieses System unterstützt mehrere Rollen, mehrsprachige Schnittstellen und optimierte administrative Arbeitsabläufe.

## 🚀 Hauptmerkmale

- **Multi-Rollen-Unterstützung**: Maßgeschneiderte Dashboards für **Administratoren**, **Lehrer** und **Direktoren**.
- **Mehrsprachige Benutzeroberfläche**: Volle Unterstützung für Arabisch (RTL), Französisch, Englisch, Deutsch, Türkisch und Tamazight.
- **Akademisches Management**:
  - Registrierung und Verfolgung von Schülern und Klassen.
  - Fächerverwaltung mit spezifischen Koeffizienten.
  - Vierteljährliche Bewertung (Trimestriel) und Noteneingabe.
- **Automatisierte Einrichtung**: Ein spezielles PowerShell-Skript für die schnelle Einrichtung der lokalen Umgebung unter Windows.
- **Berichterstattung**: Erstellung von statistischen Einblicken und akademischen Berichten.

## 🛠️ Tech Stack

### Frontend
- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **UI-Bibliothek**: [Material UI (MUI)](https://mui.com/)
- **Animationen**: [Framer Motion](https://www.framer.com/motion/)
- **Internationalisierung**: [next-intl](https://next-intl-docs.vercel.app/)

### Backend
- **Runtime**: [Node.js](https://nodejs.org/) mit **Express.js**
- **Sprache**: [TypeScript](https://www.typescriptlang.org/)
- **ORM**: [Prisma](https://www.prisma.io/)
- **Validierung**: [Zod](https://zod.dev/)

### Datenbank
- **Engine**: [PostgreSQL](https://www.postgresql.org/)

## 🏃 Erste Schritte

### Voraussetzungen

- **Node.js**: Version 18.x oder höher.
- **PostgreSQL**: Version 14 oder höher.

### Automatisierte Installation (Empfohlen für Windows)

1. Öffnen Sie ein PowerShell-Terminal im Stammverzeichnis.
2. Führen Sie das Setup-Skript aus:
   ```powershell
   ./setup.ps1
   ```
3. Folgen Sie den Anweisungen auf dem Bildschirm.
